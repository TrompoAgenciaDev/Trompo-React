## Cada página que se rediseña a partir de un html presentado:

## 1.- Debe seguir el mismo estilo que ya tiene, pero teniendo en cuenta que se ignora:
## Header
## Footer
## Dock

## Si es una sección o layout o componente que ya existe, obviamente que se utiliza el componente ya existente.

## 2.- Estilos:

## El archivo index.css ya tiene los estilos estandarizados de todas las páginas, así como la tipografía estandarizada y tamaños de fuente y colores de letra y fondos.
## Se deben utilizar las estandarizaciones, a excepción de elementos que no tengan los mismos estilos que lo que hay en el index.css En ese caso, se va a realizar un archivo nuevo de css para esa ppágina/componente.



## A tener en cuenta: 
## Si la página o componente rediseñado ya tiene una hoja de estilos, lo que se debe hacer es eliminar todos esos estilos y agregar solo los estilos que no están estandarizados y se van a utilizar en la nueva página/componente. No se debe crear un archivo nuevo, ya que acumula basura.
## Si la página o componente .jsx se rediseña, se debe eliminar todo el código que tiene el .jsx y agregar solo el código que se va a utilizar en la nueva página/componente. No se debe crear un archivo nuevo, ya que acumula basura.
